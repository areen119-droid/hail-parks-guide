# Hail Parks Guide

A Flutter app that guides tourists around parks.

## Project structure

```
lib/
  main.dart      app entry point
  app/           app widget, routes, theme
  core/          shared constants, services, utils, widgets, splash screen
  data/          static park data
  features/      one folder per feature (parks, plants, map, home, login, profile, ...)
  firebase/      Firebase options (generated by `flutterfire configure`)
  model/         park and plant models
  models/        other data models
  providers/     ChangeNotifier providers
  services/      Firebase service wrappers
```

## Setup

1. Install the [Flutter SDK](https://docs.flutter.dev/get-started/install).
2. Connect your Firebase project:

   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```

3. Add your Google Maps key to `android/local.properties`:

   ```
   MAPS_API_KEY=your-key-here
   ```

4. Install packages and run:

   ```bash
   flutter pub get
   flutter run
   ```
